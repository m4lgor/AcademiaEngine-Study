AcademiaEngine Anatomy

How the base engine is put together today: who owns what, what happens every frame, how objects come and go, and how world units become pixels.

Who owns what

AcademiaEngine owns one instance of every engine system and runs the game it is given through the GameBase class, where student code starts.

GameManager

Derives from the engine's GameBase class. main() hands it over with SetGame, so the engine never includes the Game folder. Initialize once, Update(dt) every gameplay frame, Uninitialize at exit.

From launch to exit

The whole program, start to finish. Objects added in Initialize are flushed right away, so they exist on the first frame.

Frame loop

The three phases above, as fast as the machine allows. Update runs every frame, FixedUpdate a constant 60 times per second.

OnUserDestroy

Uninitialize(), then ReportLeaks lists any object that was added but never removed.

Adding and removing, frame by frame

World units and pixels

Game code thinks in world units with Y pointing up. Only drawing converts to pixels, through the camera.

Camera fieldDefaultMeaning
Position(0, 0)World point shown at the screen center
Zoom1.02 = everything twice as big. Floor of 0.001
PixelsPerUnit50Pixels per world unit at zoom 1
Engine helperUse it for
ConvertWorldPositionToPixelsWhere to draw an object
ConvertWorldLengthToPixelsRadius, width, line length
ConvertPixelsToWorldPositionMouse clicks into the world
ConvertPixelsToWorldLengthPixel distances into units

Text drawn with raw pixel coordinates ignores the camera, which is what a HUD wants.

World positions and sizes are Vector2f. Pixel positions are Vector2i.

Dev tools on screen

What you see by default: a quiet FPS counter and the toolbar. The stats panel opens from the toolbar.

pause · step · stats
F1Show or hide the toolbar and stats panel. The FPS counter stays.
F2Pause or resume. Same as the pause button, which turns blue while paused.
F3While paused, run one update and one fixed step of exactly 1/60 s. Same as the step button.
▮▮▮Stats button: FPS and frame time, object count, camera, zoom, mouse in world units.

The FPS counter is grey when healthy, amber under 55 FPS, red under 30.

Folders and dependencies

Each folder may only include folders below it. Nothing includes upwards, and no two folders include each other.

Game

src/GameYour gameplay: GameManager and your own objects.May use Engine, Physics, Math

Engine

src/EngineLoop, Scene, GameObject, Camera, TimeControl, DevTools, the GameBase class.May use Physics, Math

Physics

src/PhysicsEverything physics you implement in the course. The folder is created when you start.May use Math

Math

src/MathVector2f, Vector2d, Vector2i, Vector2u.Uses nothing from src/

main.cpp sits above all of them. It is where the engine and the game are connected with SetGame. Run tools/CheckDependencies.ps1 to list any include that goes the wrong way and any cycle.

Still to come from the plan: time scale and slow motion, built-in shapes, more math helpers, and the physics in src/Physics.
